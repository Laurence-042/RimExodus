0.1.5
- 修复激活mod时太空地图背景被清除为黑色的bug
  Fixed a bug where the space map background was cleared to black while the mod was active
- 优化体验，邻接生成的地图保证从地图中心到接缝有一条不被岩石阻挡的走廊，避免玩家在 Geological Landforms 提供的五面环山地形走出唯一出口后发现是死路
  Experience optimization: For adjacent map generation, a corridor free of rock obstructions is guaranteed between the map center and the edge, preventing players from encountering a dead end after exiting the only opening in the "surrounded by mountains on five sides" terrain provided by Geological Landforms.
- 优化体验：重构河流相关地形生成，现在新地图上的河流的生成会更加自然，连续性也会更好
  Experience optimization: Refactored river terrain generation; rivers on new maps now generate more naturally and with better continuity.
  - 已知限制：优化过程中发现 Geological Landforms 的河流地貌会整体替换原版河流生成，这会导致GL的河流在不同地块生成的地图上不连续。如果非常在意连续性，可以在其设置中禁用全部河流地貌并打开原版河流地貌（详见 README 兼容性表）
    Known limitation: During optimization, it was discovered that Geological Landforms' river features entirely replace vanilla river generation, causing GL rivers to lack continuity across adjacent map tiles. If continuity is a priority, you can disable all GL river features in the settings and enable vanilla river features instead (refer to the compatibility table in the README for details).

0.1.6
- 修复读取旧存档（或关闭快照入存档后读档）时生成邻接地图接缝地形不连续的问题：生成邻图前若当前地图缺少地形快照，会在一张临时地图上只重跑地形/岩石/屋顶的精简生成来重建快照（每张图一次性几百毫秒），接缝混合参考由此恢复
  Fixed seam terrain discontinuity on neighboring maps generated after loading older savegames (or with snapshot serialization disabled): if the current map lacks a terrain snapshot before a neighbor map is generated, a lean regeneration (terrain/rock/roof only) runs once on a temporary map to rebuild the snapshot, restoring the seam mixing reference.
- 调整快照入存档开关的关闭语义：关闭只影响"新快照不再写入存档"，已存数据保留、内存快照常驻，且不再弹出"是否删除已有快照"的二次提示；读档后缺失的快照由上述精简重生成自动补齐
  Adjusted the snapshot-serialization toggle: turning it off only stops NEW snapshots from being written to the savefile. Existing data is kept, in-memory snapshots always remain, and the "also delete stored snapshots" confirmation no longer appears; snapshots missing after a load are rebuilt automatically by the lean regeneration above.
- 新增设置项"生成邻接地图时精简重生成缺失的快照"（默认开，可关闭以维持旧行为）
  New setting "Regenerate missing snapshots when generating neighbor maps" (default ON; can be disabled to keep the old behavior).
- 进度提示扩展：左上角生成进度条现在也覆盖同步加载阶段（旧存档的快照重建、原版管线的地图生成）——标签在生成开始前一帧点亮，卡顿期间画面上可见"正在做什么"
  Progress indicator expanded: the top-left generation progress now also covers synchronous loading phases (snapshot rebuild for older saves, vanilla-pipeline map generation) - the label appears one frame before the heavy operation starts, so the frozen frame shows what is happening.

0.1.7
- 优化多地图下的天气表现：同一片连续群系内的相邻地图现在共享同一场天气（同时下雨、同时放晴），且降雨打湿地面、积雪、闪电与天气音效在每张地图上都会正常生效——此前这些天气效果只会出现在其中一张地图上
  Improved weather across maps: adjacent maps within the same continuous biome now share the same weather (it rains and clears on all of them at once), and rain wetting, snow buildup, lightning and weather ambience now take effect properly on every map — previously these effects only occurred on one of the maps. 
- 修复仪式、灾害等强制天气在多地图环境下生效与结束时行为不一致的问题（有时会表现为卡死）（@Eziojosh02 报告的问题）
  Fixed inconsistent behavior of forced weather (rituals, disasters, etc.) starting and ending in multi-map environments(sometimes causing the weather to remain stuck on a specific type). (@Eziojosh02's reported issue)
- 设置中新增按模块开关的诊断日志（生成、传送、远行队离场、天气等 9 个模块）：向作者报告问题时只需打开相关模块，日志干净易读；同时清理了部分此前始终输出的调试信息
  Added per-module diagnostic logging toggles in the settings (generation, transfer, caravan exit, weather, etc. — 9 modules): when reporting a problem you only need to enable the relevant module, keeping logs clean and readable; some debug messages that were always printed are now cleaned up.
- 世界地图上选中已生成地图的派系基地等地点对象时，现在也可以手动休眠/删除（此前仅无缝地块图支持）。删除按原版规则处理：派系基地删图后世界对象保留、再次靠近时重新生成驻军，其余地点（伏击、战场等）连对象一并移除；图上有殖民者/运输舱等阻碍移除的单位时删除不可用（按钮灰显并提示原因）（@Hezmana 和 @Eziojosh02 报告的问题）
  Faction bases and other location objects with generated maps on the world map can now be manually suspended/deleted (previously only seamless tile maps had this). Deletion follows vanilla rules: faction bases keep their world object and regenerate their garrison when revisited, while other locations (ambushes, battlefields, etc.) are removed entirely; deletion is unavailable (button greyed out with a reason) while pawns or transporters block map removal. (@Hezmana and @Eziojosh02 reported this issue)
- 修复 Perspective Shift 第一人称模式下持续按住方向跨缝时，在两张地图间来回弹射的问题（@Hezmana 报告的问题）
  Fixed pawns bouncing back and forth between two maps when holding a movement direction across a seam in Perspective Shift first-person mode. (@Hezmana's reported issue)
- 修复当使用原版地图生产流程时，生成进度标签来不及显示、卡顿期间画面上没有任何提示的问题
  Fixed the progress label failing to appear in time during vanilla map generation, leaving no feedback while the game was freezing.

0.1.8
- 修复内存泄漏：长时间游玩不断探索新地块时，已删除地图的内部数据会一直残留在内存中（每张图约几 MB，探索越多积得越多），现在这些数据会随地图删除一起释放；从主菜单读取其他存档或开新档时也会彻底清理一遍
  Fixed a memory leak: during long playthroughs with continuous exploration, internal data of deleted maps (a few MB each) kept lingering in memory and piled up as you explored. This data is now released together with its map, and fully cleared when loading another savegame or starting a new one from the main menu.
