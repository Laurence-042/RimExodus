  Improved weather across maps: adjacent maps within the same continuous biome now share the same weather (it rains and clears on all of them at once), and rain wetting, snow buildup, lightning and weather ambience now take effect properly on every map — previously these effects only occurred on one of the maps.

  Fixed inconsistent behavior of forced weather (rituals, disasters, etc.) starting and ending in multi-map environments(sometimes causing the weather to remain stuck on a specific type). (@Eziojosh02's reported issue)
- 设置中新增按模块开关的诊断日志（生成、传送、远行队离场、天气等 9 个模块）：向作者报告问题时只需打开相关模块，日志干净易读；同时清理了部分此前始终输出的调试信息
  Added per-module diagnostic logging toggles in the settings (generation, transfer, caravan exit, weather, etc. — 9 modules): when reporting a problem you only need to enable the relevant module, keeping logs clean and readable; some debug messages that were always printed are now cleaned up.

  Faction bases and other location objects with generated maps on the world map can now be manually suspended/deleted (previously only seamless tile maps had this). Deletion follows vanilla rules: faction bases keep their world object and regenerate their garrison when revisited, while other locations (ambushes, battlefields, etc.) are removed entirely; deletion is unavailable (button greyed out with a reason) while pawns or transporters block map removal. (@Hezmana and @Eziojosh02 reported this issue)
- 修复 Perspective Shift 第一人称模式下持续按住方向跨缝时，在两张地图间来回弹射的问题（@Hezmana 报告的问题）

  Fixed a memory leak: during long playthroughs with continuous exploration, internal data of deleted maps (a few MB each) kept lingering in memory and piled up as you explored. 0.1.9
- 装有 Geological Landforms 时不再需要手动关闭它的河流地貌：河流现在会在相邻地块之间连续流动（此前若不关闭，河在地块交界处会错位断裂）。注意只对新生成的地图生效，已生成过的地图不会变化
  Geological Landforms' river landforms no longer need to be disabled manually: rivers now flow continuously across neighboring tiles when GL is installed (previously rivers would be misaligned and broken at tile borders unless you disabled them). Note this only applies to newly generated maps; already-generated maps are unaffected.
- 前哨保留：你建造过的地图（画了居住区的）离你太远时不再被完全删除，居住区里的建筑、地板、屋顶和留下的物资会被"封存"到硬盘——地图不再占用内存，但修改仍能保留；你再回来时地图重新生成，你的前哨会在原样重建（居住区内挖开的山体也不会复原）。封存的地块在世界地图上显示青绿色，不想要了可以在上面选"丢弃已封存"来删掉对应地图的封存数据
  Outpost preservation: maps you have built on (with a home area drawn) are no longer fully deleted when they get too far away. Buildings, floors, roofs and items left inside the home area are "archived" to disk — the map no longer occupies memory, but your changes are preserved. When you come back, the map regenerates and your outpost is rebuilt as it was (mountains you mined out within the home area stay mined, too). Archived tiles show a teal color on the world map; if you no longer want one, select the tile and choose "Discard archived data" to delete that map's archive.

  New: maps with active enemies (raiders, angered insects, etc., including hostile settlement garrisons) now always simulate at full speed instead of being throttled, and fall back automatically once the enemies are gone; a low-priority alert on the right lists which maps are being kept at full speed. Note that hostile settlement garrisons never leave, so their maps stay at full speed while you're nearby.

  Fixed: retreating enemies used to vanish into thin air at seams where both sides had maps. They now actually cross the seam into the neighboring map and keep fleeing until they leave your explored area; if there's no map on the far side, they walk up to the seam before departing. Visiting caravans and other departing NPCs benefit as well.

  Fixed: some Odyssey terrain features or quest locations could generate content that should have been mutually exclusive; frame-sliced map generation now follows the same exclusion rules as vanilla.
- 修复：读取存档后恢复地图边缘时，部分常见地形、岩石或屋顶可能被误当成空白；新旧存档现在都能正确识别这些数据
  Fixed: when restoring map edges after loading a save, some common terrain, rock, or roof data could be mistaken for empty entries; both new and existing saves now resolve this data correctly.
- 修复：河中岛地貌的河道仍可能在相邻地块交界处错位；现在它也使用与普通河流相同的接缝对齐修正（仅影响新生成地图）
  Fixed: rivers using the river-island terrain feature could still be misaligned at neighboring tile borders; they now receive the same seam-alignment correction as ordinary rivers (newly generated maps only).
- 修复：隐藏休眠地图或空地图的顶部殖民者栏分组后，图标位置和拖动分组可能错位，极端情况下会引发界面报错
  Fixed: after hiding dormant or empty map groups from the colonist bar, icon positions and drag groups could become misaligned and, in edge cases, cause UI errors.
- 修复：分帧地图生成失败后，同一地块可能在本次游戏中一直无法重试生成；失败残留现在会被完整清理
  Fixed: after frame-sliced map generation failed, the same tile could remain impossible to generate again during that game session; failed-generation state is now cleaned up completely.
