0.1.1

Added an option to hide empty map entries from the top map bar
- 修复了远行队的问题
Fixed caravan-related issues
- 修复了存档读档后无法跨图的问题
Fixed the issue where cross-map functionality stopped working after loading a save
- 精简发布包大小
Reduced release package size

0.1.2
- 优化性能
Improved performance
- 优化邻接地图加载机制，允许短时间触发多个邻接地图的加载
Improved the adjacent map loading mechanism, allowing multiple adjacent maps to be loaded within a short period of time
- 修复邻接地图的动物被渲染在迷雾上方的 bug
Fixed a bug where animals on adjacent maps were rendered above the fog of war

0.1.3
- 优化地图生成机制，应该有助于避免出现奇怪的石墙（@辰 报告的问题）
Improved the map generation mechanism, which should help prevent strange rock wall formations (@辰's reported issue)
- 优化地形探针的输出内容，让调试更加简单
Improved terrain probe output to make debugging easier
- 优化 pawns 归属地块状态追踪机制，应该有助于避免出现殖民者偶尔被同时计在两个地点的问题 bug（@rex20d 报告的问题）
Improved pawn location tracking, which should help prevent the bug where colonists were occasionally counted as belonging to two locations at the same time (@rex20d's reported issue)
- 添加主动将地图恢复为兼容原版的状态，以可控地卸载 mod 的功能（路线计划的一部分）
Added the ability to actively restore maps to vanilla-compatible states, allowing controlled mod unloading (part of the roadmap)
- 将休眠和删除阈值下界设为 2，并避免设置为 1 时频繁休眠删除带来的体验问题
Increased the minimum suspension/deletion threshold to 2, avoiding the poor experience caused by frequent suspension and deletion when set to 1

0.1.4
- 修复偶现的与 Dubs Mint Minimap 共同使用时 OnGUI 每帧空引用崩溃的bug
Fixed an intermittent NullReferenceException crash occurring every frame in OnGUI when used alongside Dubs Mint Minimap.

0.1.5
- 修复激活mod时太空地图背景被清除为黑色的bug
Fixed a bug where the space map background was cleared to black while the mod was active
- 邻接生成的地图保证从地图中心到接缝有一条不被岩石阻挡的走廊（只影响岩石生成，不改动地形）；走廊端点按邻图接缝带的可达性分集合选取，多个已生成邻居的地图会生成连通各方向的洞穴网络
Maps generated as neighbors are now guaranteed a rock-free corridor from the map center to the seam (only affects rock generation, never modifies terrain); corridor endpoints are selected by grouping cells on each neighboring map's seam band by reachability, and maps with multiple generated neighbors get a cave network connecting all directions
