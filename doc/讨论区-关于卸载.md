## 关于卸载 RimExodus / About uninstalling RimExodus

RimExodus 对存档的改动很深（自定义地形、传送点、地块图对象等），直接删除 mod 再读档会得到损坏的存档：残留的 mod 对象无法解析，游戏连续报错、部分地图不可用。
RimExodus changes saves deeply (custom terrain, transfer spots, tile-map objects, ...). Removing the mod outright leaves a broken save: leftover mod objects can't be resolved, the game spams errors and some maps become unusable.

因此卸载前必须先在存档内执行一次"恢复原版兼容模式"。
That's why you must run "Restore vanilla compatibility" inside the save once before uninstalling.

### 执行流程 / How to do it

**1.** 确认没有地图正在生成（屏幕左上角无 "Generating map..." 进度提示；如有，等几秒让它完成）。
**1.** Make sure no map is generating (no "Generating map..." progress text at the top-left; if there is, give it a few seconds).

**2.** 把所有殖民者撤出"无缝地块图"——即你徒步探索过的荒野地块和"设立营地"生成的地图（世界地图上带状态图标的地块即是）。恢复会**删除这些地图**，留在上面的物品、建筑、动物全部丢失。家园地图和派系据点地图不受影响。撤离方法：直接走回家（跨缝走回来，或就地组远行队回家）。
**2.** Evacuate all colonists from "seamless tile maps" — the wilderness tiles you explored on foot and maps from "set up camp" (tiles with status icons on the world map). The restore **deletes those maps**; anything left on them — items, buildings, animals — is lost. Home maps and settlement maps are not affected. To evacuate: walk home across the seams, or form a caravan back.

**3.** 进入 Mod 设置 → 高级诊断 tab → "恢复原版兼容模式（卸载前）"按钮，确认执行。如果有殖民者还在地块图上，按钮会拒绝执行并列出所在地块，撤走后重试即可。
**3.** Go to Mod settings → Advanced tab → "Restore vanilla compatibility (before uninstalling)" and confirm. If colonists are still on tile maps, the button refuses and lists the tiles — evacuate and retry.

**4.** 看到完成消息（几张地图按快照恢复、几张降级恢复、删除了几张地块图）后，**立即存档**。
**4.** When the completion message appears (maps restored from snapshots, degraded ones, tile maps deleted), **save the game immediately**.

**5.** 关闭游戏，取消订阅/删除 RimExodus，再读取刚才的存档。
**5.** Quit the game, unsubscribe from / remove RimExodus, and load that save.

### 预期结果 / What to expect

家园与据点地图完整保留：建筑、物品、小人、地形修改都在；接缝处的不可通行区域恢复为可通行地形，传送点等 mod 物件被清除。
Home and settlement maps keep everything: buildings, items, pawns, terrain edits. The impassable seam regions become walkable terrain again; teleport spots and other mod objects are removed.

无缝地块图从存档中消失。原版没有"徒步进入相邻地块"的机制，之后探索世界请使用原版远行队（世界地图重访这些地块会按原版方式重新生成地图）。
Seamless tile maps vanish from the save. Vanilla has no "walk into the neighboring tile" mechanic, so explore with vanilla caravans from now on (revisiting those tiles generates maps the vanilla way).

首次读取恢复后的存档会出现一批 "Could not find class RimExodus..." 红字：这是残留的 mod 组件节点找不到类，原版自动以空组件替代——完全无害；读档后再存一次档，这些红字就永久消失了。
The first load of the restored save shows a batch of "Could not find class RimExodus..." red errors: leftover mod component nodes with no class — vanilla substitutes empty components. Completely harmless; save once more and they are gone forever.

之后即可正常游玩或迁移到其他 mod 组合。
After that the save plays normally with any mod setup.

### 关于"基础地形快照" / About "base terrain snapshots"

恢复时接缝区域的地形按 mod 记录的"裁切前快照"回填（含岩石与屋顶）。
Seam regions are restored from the mod's "pre-clipping snapshots" (rocks and roofs included).

快照默认随存档保存（设置中"将基础地形快照存入存档"，默认开）。
Snapshots are saved into the savefile by default ("Save base terrain snapshots" in settings).

关闭过这个开关的话，无快照的地图只能降级为"就近复制边界地形"回填——边缘观感明显更差，岩石与屋顶完全无法恢复。不确定的话保持默认开启即可。
If you turned that off, maps without a snapshot fall back to copying nearby border terrain inward — noticeably worse edges, and rocks/roofs can't be restored at all. When in doubt, leave it on.

### 已知限制（受地图生成机制所限） / Known limitations (inherent to map generation)

**1. 快照不是最终地形。** 快照拍摄于地图生成过程中——植被等后续内容尚未生成，地形也可能与最终结果有细微差别，因此恢复后地图边缘可能出现可见的六边形岩石边界之类的不自然特征。但仍然比没有快照的情况好得多。
**1. The snapshot is not the final terrain.** It is taken mid-generation — plants and later steps not yet done, and the terrain may differ slightly from the final result — so restored map edges can show visible artifacts such as a hexagonal rock boundary. Still far better than the no-snapshot fallback.

**2. 接缝混合差异。** 每张地图生成后会根据相邻地图的地形做跨缝混合，混合后的最终地形可能与快照差异较大，这也会在恢复后留下可见的不自然痕迹（例如岩壁形状与周边不完全衔接）。
**2. Seam-blending differences.** After generation, each map's seam region is blended with its neighbors; the blended final terrain can differ considerably from the snapshot, which also leaves visible artifacts after restore (e.g. rock walls that don't quite line up with their surroundings).

**3. 不要在盟友据点里开始卸载。** 原版逻辑中没有和平进入据点的方式（默认所有据点都是敌对的），据点地图里没有敌人就会被原版视为"据点已被摧毁"。恢复会保留据点地图，因此如果盟友（友好派系）据点的地图已经生成且仍存在，卸载后首次读档时它会被原版判定摧毁（变废墟、驻军消失）。建议：卸载前先远离盟友据点（默认 3 个地块以上），让它的地图被距离清理机制删掉，再执行恢复；或接受该据点被摧毁的后果。
**3. Do not start the uninstall while inside an allied settlement.** Vanilla has no way to enter a settlement peacefully (all settlements are assumed hostile), so a settlement map with no enemies in it is treated as "already defeated". Restore keeps settlement maps — so if a friendly settlement's map still exists in the save, the first vanilla load after uninstalling will mark it destroyed (ruins, garrison gone). Recommendation: before restoring, move far away from allied settlements (3+ tiles by default) so their maps get rolled away by the distance cleanup, or accept losing them.
