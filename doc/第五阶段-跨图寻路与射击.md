## 阶段目标

实现 Pawn 跨地块追击入侵者所需的能力：跨地图寻路、跨地图视线、跨地图目标搜索与射击。对应主文档核心交互场景中"位于地图 A 的 pawn 仍能正常射击地图 B 的敌人，敌人也能正常回击"与"玩家不能靠跨图甩掉追兵"两条。

放最后的原因（主文档路线图）：VMF 经验表明跨图射击是整套框架里最脆弱、版本最敏感的部分（IL Transpiler 级别的 `Thing.Map`/`Position` 替换），前期架构（六边形几何、连续地形、坐标映射）变动极易使其返工。

## 实现历程（按落地顺序）

### 1. 边界行为：传送许可登记制（先行落地）

判定收拢原则——传送资格不在踩点时判定，状态变更事件处登记许可（Grant）并绑定传送点，踩点热路径只查登记表，**无许可不传**（"闲逛/工作/无 flag 逃跑一律无事"成为结构性结果）。四类 Grant：Bridge（玩家跨图 goto）/ Evacuation（NPC 撤离链，VisitedTiles 防回弹）/ Pursue（跨图追击）/ Follow（跟随跨图）。历史教训：旧的 pawn 级防反弹锁已删除（"站在任一传送点保持"语义会卡死沿相邻边带内行走的撤离者）。

### 2. 跨图视线与射击线

统一坐标模型（宿主 = 射手图）：`unified = targetLocal + offset`（邻居表契约原式）。分段 LOS 逐字段复刻 `GenSight.LineOfSight` 骨架，逐格阻挡按归属图路由。准入门限经用户定夺放宽为"**看得见就打得着**"（多边形可路由，目标统一格不再要求本图方形内）。

### 3. 弹道：缝交接（对 VMF 的架构偏离）

VMF 的"弹丸全程飞基底图 + 逐调用点 transpiler 合并查询"前提是载具图与基底图物理重叠；本 mod 邻图并排不重叠，前提不成立。改为**缝交接**：弹丸在射手图飞、跨缝瞬间平移 origin/destination 后 respawn 邻图续飞（拦截/命中/爆炸 100% 原生）。全 mod 仅 `TryCastShot` 开头一处 transpiler（放行原版"目标图≠施法者图"硬拒绝），其余全部 Prefix/Postfix——transpiler 纪律与两案 Mono InvalidProgramException 教训见 `AGENTS.md`。

### 4. 索敌：原版两层模型（agent 实证勘误后复刻）

原版真相（勘误前的错误心智模型已废弃）：

- **感知层**：`AttackTargetsCache` 按阵营全图注册，无距离概念。
- **推进层**：`JobGiver_AIGotoNearestHostile`（AssaultColony duty 树第⑥位 fallback）全图无半径扫缓存取最近 + CanReach → `Goto(目标 thing)`——**从不写 `mindState.enemyTarget`**；有本图建筑时第⑤位 `AITrashBuildingsDistant` 优先（"有建筑优先拆"）。
- **接战层**：`AIFightEnemies → BestAttackTarget(maxDist=65)`（56 是从不生效的代码默认值，Core XML 全覆写 65/72），65 内无需 LOS，获取不查武器射程（射程属于 CastPositionFinder 抵近层）。

跨图 patch 面：`BestAttackTarget` Postfix（本图优先，为空才扫活跃邻图 + "当前可射"门控）、`GotoNearestHostile` Postfix（邻图取最近 + `CanBridgeTo` 替代 CanReach + 复刻原生 Goto）、`AIFightEnemy` 两 patch（Wait_Combat 兜底 + ShouldLoseTarget"当前可射"保持）。用户定夺：**只 patch 获取和寻路，勿回退为逐行为处理**。

### 5. 跨图交互二次重构：点击重放 + 公共函数层（VMF 同构）

点击本图区域 = 完全原生；点击本图渲染的邻图区域 = 拦截点击在**真邻图上重放**拿原生选项与命令（FloatMenuContext ctor 参数注入），公共函数（可达性/选位/下令/距离）跨图化（CanReach 真实化 / 虚拟传送选位 / PawnGotoAction 桥接 / StartPath 包装）。历史首版"点击复现"（GetOptions 整方法接管 + 手写注入选项 + 多层拦截）已整体删除——教训：手写注入连续漏原版目标语义、多层拦截产生混框架乱坐标、CanReach 安静 false 使"看得见的敌人"全体禁用攻击；架构层（重放 + 公共函数）才是正解。

### 6. 敌人侧推进与追击链

- **推进桥接**：GotoNearestHostile 跨图版下发的 Goto 经 `StartPath` Prefix 识别后桥接（`TryBridgeJob` 单跳双侧代价场联合最优选点），传送后续跑原 Goto 走向目标，途中进接战圈被原生 AIFightEnemies 接管。
- **追击链**：目标跨图瞬间 `MarkPursuers` 扫描出发图 NPC 战斗体，意图三判据（AttackMelee/AttackStatic job、非 playerForced 推进 Goto 的 targetA、`mindState.enemyTarget`）；远程者还能跨缝射则原地继续打；追击者落地由追击 lord 接管（`LordJob_AssaultColony`，防无 lord 被 `JobGiver_ExitMap` 离场"传送后消失"）；战斗踩点资格兜底沿缝走位者的即席 Pursue。

### 7. 历轮断链存档（索引）

敌人跨图索敌历轮"看起来没生效"的根因记录在 [跨图命令适配审计](跨图命令适配审计.md) 第四节：

1. 第一轮：`AIFightEnemy.TryGiveJob` 的 Wait_Combat 捷径与 CastPositionFinder 在混算坐标下全灭（→ TryGiveJob Postfix 兜底）；`ShouldLoseTarget` 每 tick 丢跨图目标（→ "当前可射"保持判据）。
2. 第二轮（2026-08）：`ThinkNode_Duty.TryIssueJobPackage` 无条件覆写 think tree job 的 `dutyTag` → 旧 `NpcApproachTag` 自标识从未生效，**推进 job 从未被桥接**（→ StartPath 识别改结构判据：非 playerForced 的 Goto 且 targetA Thing 在邻图）。教训：**job.dutyTag 不能作为 think-tree job 的自标识通道**。

## 与原计划的偏离（用户定夺）

- **单跳桥接**：跨图 A* 只做单跳（双侧代价场在过缝点处可分解，等价全局最优过缝点），不做多跳地图图（`doc/第二阶段-最小技术原型.md` 的约束延续）。
- **门限放宽**："看得见就打得着"——准入门限 = 多边形可路由，仅逐格阻挡按归属图路由。
- **两层模型**：只 patch 获取和寻路，不做逐行为处理（CastPositionFinder 跨图走位候选仍为观察项）。
- **近战跨图索敌不做接战层扫描**（BestAttackTarget Postfix 仅远程投射物）：近战走推进层 + 追击链过缝。

## 阶段外增量交叉（2026-08 Settlement 无缝接入，叙事注记）

阶段5 机制与后续落地的"其他派系 Settlement 无缝接入"（走近原生生成 + 据点贸易商，权威 = `AGENTS.md`"地图生命周期"节与 [地图滚动休眠](地图滚动休眠.md) 2.11 末段）在三个点上交叉，均无需新增 patch：

- **敌对据点驻军直接进入本阶段全部语义**——预加载生成的敌对据点图就是普通活跃邻图：驻军可跨缝索敌（BestAttackTarget/GotoNearestHostile 邻图扫描）、推进桥接过缝、被反击时追击链/战斗踩点照常工作（回归项 = `AGENTS.md` 当前待办清单第 11 条"驻军可跨缝索敌"）。
- **揭雾分径与索敌正交**：跨图索敌候选刻意不做 fog 过滤（"看得见就打得着"，可见性口径跟渲染走），故 `Patch_GenStep_Fog_SeamOrigin`（邻接生成只从生成方向接缝洪水揭雾）不影响战斗判定，只影响玩家视野与贸易商可点击性。
- **远行队出口链修复属边缘行为统一（阶段4b 域）**：5 参 Rot4 `TryFindRandomEdgeCellWith` 接缝化 + `RegionMaker.AddCell` 触边六边形化（district/Room.TouchesMapEdge 对区域系统整体变为六边形边——倾斜图组队全链走通，兼修袭击入口 EdgeWalkIn 选点与打包点搜索）。权威 = `AGENTS.md`"边缘行为统一"节；历史教训（曾据"未倾斜图 4/6 tiles 正常"误判回退——那只是六边形角点恰好轴对齐触方形边的侥幸）已记入该节勿回退要点。
