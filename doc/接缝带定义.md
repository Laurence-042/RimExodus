# 接缝带定义（权威）

> 状态定稿 2026-08。本文是接缝带几何的**唯一权威定义**，代码与文档统一用词以本文为准。
> 实现入口：`Source/SeamlessPolygonGeometry.cs`（`BuildSeamBand` / `SeamBandInfo`）。

## 0. 背景与动机

旧架构中"接缝带"没有显式定义：传送点带 = 距 void 边界切比雪夫 1..2 格（`ComputeVoidBand(N=SeamOverlap)`），
offset = 源图多边形镜像假设 `round(2·(midA−centerA) − SeamOverlap·unit)`。两图多边形各自用自己
tile 中心的切平面基独立投影，同一条世界共享边在两端局部坐标系中的内切距不等（顶点方向角间隔
差 1° ≈ 内切距差 ~1 格），镜像假设把 A 的内切距强加给 C → **系统性 ±1 格渲染错位**（2026-08 实测：
聚焦 C 时 C 的接缝带比 A 背景内偏一格；赤道正北侧同样复现，排除地块角度因素）。

本次重构把接缝带显式定义，并把偏差吸收职责从"offset 固定收缩 2 格"移交"3 圈接缝带"。

## 1. 术语体系

以**离散边为锚**的方向词：**接缝带内** = 核心侧（朝地图中心）；**接缝带外** = void 侧。

**禁止**用"六边形外/内"指格集合——离散边格横跨连续边，内外归属有歧义。"格中心在多边形内/外"
（`ContainsPointAt(格中心)`）仅作为无歧义的标量判定使用。

## 2. 定义

从核心区向外的圈层顺序：

```
核心区 → 带内圈 → 离散边圈 → 带外圈 → void（接缝带外）
        └──────── 接缝带 B ────────┘
```

| 术语 | 定义 |
|---|---|
| **连续边** | 多边形顶点（内切圆模型，`BuildPolygonVertices`）环连成的 n 条浮点线段 `(verts[j], verts[(j+1)%n])`。N=5/6 通用。 |
| **离散边 D（离散边圈）** | 格方块 `[x,x+1]×[z,z+1]` 与任一连续边线段**相交**（slab 法，含边界/角点接触）的格集合。横跨连续边，不参与内外分类。恰好经过四格公共角时 2×2 格都入 D。 |
| **接缝带 B** | `Cheb(D, 1)` = 离散边 + 切比雪夫内外各一圈，约 3 圈厚。对角接触被切比雪夫膨胀填满，**无洞**。 |
| **带内圈** | `B − D` 中格中心在多边形内的格。无传送点。 |
| **带外圈** | `B − D` 中格中心在多边形外的格。**实地形**（不再是 void），属传送圈。 |
| **传送圈** | `D ∪ 带外圈`（外侧 2 圈）。传送点铺设范围（`Standable` 过滤后）。 |
| **void（接缝带外）** | 格中心在多边形外且 `∉ B`。铺 `RimExodus_Void`。 |
| **核心区** | 格中心在多边形内且 `∉ B` 的格。 |
| **过渡带 T** | 接缝带内（核心侧）距 B ≥1 的**全部**格（膨胀到核心区穷尽）。SeamOverride 混合枚举范围（运行时 strip 无命中的格自然跳过）。 |
| **接缝带外条带** | 接缝带外（void 侧）**全部**格（膨胀到方形边穷尽）。void 区，其原生三层快照是新图混合的参考数据——**全深存储**（权重衰减轴需要：接近源六边形高 → 源方形边 0）。 |

### void 判定的防孤岛等价性

新判定"中心在外且 ∉B"取代旧"中心或 4 角任一在内→非 void"的角检测。凸多边形下，角在内的格
必属 `{中心在内} ∪ D`（格方块与多边形有面积交集 ⟺ 中心在内或某条边线段穿过格方块）⊆
`{中心在内} ∪ B`，故两者防孤岛等价；差集恰为带外圈（有意从 void 变实地形）。

### 传送圈为何只有外侧 2 圈

传送落点 = `spot − offset`，中点对齐的取整残差 ±1 格由对侧 3 圈带吸收：pawn 由内向外正常
移动必先踩**离散边圈** spot（更靠内），落点理想在对侧离散边圈，偏移最多落到对侧带内圈/带外圈
——均为实地形，不进 void。若带内圈也有传送点，站带内圈传送的落点偏移可能越过对侧带外圈落进
void。极端组合（站带外圈 + 对端近 1 格）落点 void 由 `Walkable` 检查严格拒绝（不做回退——
寻路已排除不可站立 spot，正常移动流不触发）。

## 3. offset：连续边中点对齐

```
offset(A→C) = round(midA_jA − midC_jC)
```

- 契约不变：`neighborLocal + offset = myLocal`；`midNew + offset = midSource` 即两端连续边中点平移后重合。
- jA/jC = 共享边在各自多边形中的边索引（`WorldTileGeometry.FindNeighborIndex`，"边 j ↔ 邻居 j"同构）。
- **双端几何参与**（旧镜像假设只用源端——系统性 ±1 格错位的根因，勿回退）。
- **无收缩**（旧 SeamOverlap 收缩已废弃；偏差吸收移交 3 圈带）。
- 天然对称：`round(−x) = −round(x)`，任一端计算结果一致；登记时算一次取负。
- 取整残差 ≤1 格/分量；渲染保持整数 TRS 平移（浮点平移会引入半格纹理错位，不做），
  残差由"带外圈实地形 + 重叠带地形完全一致 + 聚焦图覆盖"掩盖。
- 旧常量 `SeamOverlap` 改名 `RoadAnchorInset = 2`，仅剩道路锚点内偏语义。

## 4. SeamOverride：接缝条带快照参考

### 数据（`SeamStripData`，平行三层快照：terrain 层 + building 层 + roof 层）

每图捕获一次（genStep 1410 末尾，混合完成后）。三层同点位、同来源、同查询：

- `B ∪ T` 格 → **最终实况**（重叠区参考源，"完全一致"用）；
- 接缝带外条带格 → **原生快照**（1400 同点位备份 `baseTerrainSnapshot`/`baseBuildingSnapshot`/`baseRoofSnapshot`；衰减区参考源）——building/roof 层必须用原生（void 铺设已清掉外条带岩体与屋顶）；
- building 层存岩石体 BuildingDef（null=无）：照抄区 spawn 用对端 def（跨缝岩色连续；原版岩石地形阈值 elevation≥0.61 与 Building 阈值 >0.7 不同的中间带状态正确继承）；
- roof 层存 RoofDef（null=无）：照抄区屋顶照抄对端（岩壁带原生岩顶 Thick/Thin，不裸顶）。

存储：地块图挂 `MapParent_SeamlessTile.seamStrip`（WorldObject，序列化）；锚点图挂
`SeamlessTileManager.anchorSeamStrip`。

### 清理时序（全部归 1400，勿在更早步骤预清）

order 200 的 `Patch_GenStepRocksFromGrid` 已删除（2026-08）。原生数据（含接缝带外条带的
岩体/屋顶）在 1400 `BackupSnapshotAndApplyVoid` 先落三层快照，再由 `ApplyPolygonTerrain`
依次清 roof → rock（实体）→ terrain。历史教训：曾在 200 预清 void 格岩体，外条带原生
岩体在备份前丢失 → 新图照抄区岩壁整齐切断。

### 混合规则

SeamOverride 只做三件事：**按卷积权重覆盖、随机化边缘（dither）、道路修复（保护）**。规则轴 = **本端圈层**（对端只提供数据，不参与规则判定——错位天然免疫）：

- **c ∈ B_C（接缝带三圈）→ 三层字面照抄对端对应格**：`a = c − offset`，邻居条带快照有数据即抄地形、岩体（对端 def——跨缝岩色连续）、屋顶（对端原生岩顶，防裸顶岩壁；地形未变时岩体/屋顶同步仍执行；无任何地形例外）。历史版本按对端圈层（B_A/T_A/外条带/核心区）分四条规则 + 错位补偿补丁，已废弃勿回退。
- **c ∈ void_C → 不在枚举范围**：直接用自己的 void。
- **c ∈ T_C（过渡带）→ 卷积权重覆盖（源地图轴权重）**：w = `dSq/(dSq+dOut)`——dOut = a 距源接缝带切比雪夫深度（B/T 区=0），dSq = a 到源方形边切比雪夫距离。**接近源六边形权重高，到源方形边渐近 0**——混合范围截止边界（源方形边）恰是权重归零处，自然闭合无锐利边缘；×乘性 dither（端点 0/1 不动）打散等值线。self（C 当前 topGrid 3×3，越界 clamp）+ 各参考（快照 3×3，缺格跳过）加权 → 众数（平局 defName 稳定决胜）覆写；**岩体/屋顶跟随主导参考（w 最大）的 def**——与照抄区语义统一（地形走卷积混合，离散层跟随参考；地形驱动 spawn 会在参考无岩体处生成本端岩体，2026-08 用户实测不一致后修正）。历史教训勿回退：按"本端固定深度衰减 + 外条带限深"会让数据边界处权重残值戛然而止，源方形边在 C 上投影成一条直线。
- **顶点楔形区**（B_C 多邻居命中）：卷积合成（各 w=1，Σw ≥ 1 时 self 权重 0）——替代旧"串行后写者胜"。
- **唯一例外 = 道路保护**：路是 1-2 格窄结构，3×3 众数卷积必然抹掉（窗口内少数派），且路由 A* 权威生成——①本格 IsRoad/bridge 跳过；②`SeamlessRoadPaths` ±3 格切比雪夫缓冲兜底无 tag 路面（Gravel 等）。
- **水体无例外（用户定夺 2026-08，勿回退为裸 IsWater 或"不可走水体"判定）**：对端是水体本端就是水体——不能走 pawn 自然绕路（与地图中央的水体同构）；河/海走廊位置由 river patch 端点对齐权威保证，SeamOverride 的逐格混合负责接缝两侧地形一致，两者互补。历史的水体例外（本格 IsWater 跳过、卷积采样跳水）是旧 offset ±2 格系统误差下"防水蔓延"的补丁，中点对齐后不成立（其间还因 `HasTag("Water")` 前缀匹配误伤 WaterMarshy 的 Marsh 造成接缝断裂）。
- **单向**：只改 C。先生成者原生，后生成者服从（先生成时对端不存在是自然序）。

### 旧候选枚举废弃

旧方案从 A 全图 snapshot 枚举候选（`cCell = aCell + offset` 落 C 六边形内）——A 方形角落格
绕六边形顶点投影进 C 侧向楔形区的污染（`A(249,249)→C(59,146)` 实测数据点）由此结构性消失：
只枚举 C 的带格，每格反向找邻居参考。

## 5. 地图生命周期（滚动加载卸载预埋）

| 状态 | 现状对应 | 接缝参考数据 |
|---|---|---|
| 已加载 | 图在 `Find.Maps`（全量模拟、随存档序列化、读档恢复不重生成） | 活图存储位（生成期写入） |
| 休眠（未来滚动卸载） | 当前不存在（所有已生成图常驻）；预埋路径 = 卸 Map、留 WorldObject | `TryGetNeighborSeamStrip` 的 WorldObject 回落路径（已实现） |
| 完全卸载 | 仅 Dev `RemoveTileMap`（销毁 Map **和** WorldObject） | 无（"完全卸载 = 从未出现过"） |

统一取数入口 `SeamlessTileGraph.TryGetNeighborSeamStrip(worldTile)`：①活图 → 活图存储位；
②`Find.World.worldObjects.MapParentAt(tile)` 上的 `MapParent_SeamlessTile` → WorldObject 快照；
③都无 → 不参考。未来实现滚动卸载时参考链路零改动。

**读档缺口修复**：旧 `baseTerrainSnapshot` 非序列化且读档无重建 → 读档后新生成图的接缝混合静默
失效。序列化的 `SeamStripData` 解决（外条带原生值跨读档可用）。

## 6. 参数表

| 参数 | 值 | 位置 | 语义 |
|---|---|---|---|
| `SeamStripInnerDepth` | 6 | `SeamlessPolygonGeometry` | 条带快照 B∪T（最终实况区）存储限深（只服务错位 ≤3 格的浅层照抄参考）；外条带不限深（存到源方形边） |
| `RoadAnchorInset` | 2 | `SeamlessTileManager`（旧名 SeamOverlap） | 道路接缝锚点内偏格数（河流锚点 0 不变） |

| `seamOverrideNoiseAmplitude` | 0.15 | 设置（ModSettings） | 衰减区权重 dither 幅度（乘性；完全一致区不受影响） |

## 7. 消费方总览

| 系统 | 使用的定义 |
|---|---|
| void 铺设（`ApplyPolygonTerrain`，1400） | void = 接缝带外 |
| 清岩（`Patch_GenStepRocksFromGrid`，200） | 清岩范围 = void（接缝带外）；**接缝带 B 上的岩石保留**（岩石属带的自然地形，混合时由 SyncRockBuilding 按最终地形增删——曾扩到 void∪B 导致锚点图接缝带岩石永久缺失，已回退） |
| 传送点（`PlaceEnterSpotsAllNeighbors`） | 传送圈 = D ∪ 带外圈，**无任何可通行性过滤**（spot 是纯逻辑连接：能不能走由地形运行时决定，不能走 pawn 自然绕路；地形变化后即时可用） |
| 边缘行为（`SeamlessEdgeCells` → ExitMapGrid/CellFinder/Reachability/预加载排除） | 复用传送点格集合（自动跟随） |
| SeamOverride（1410） | 混合范围 B∪T、邻居参考规则、条带快照 |
| 条带快照捕获（1410 末） | B∪T + 外条带 |
| 预加载带/禁建带（`SeamlessBorderLookup`） | `ComputeVoidBand` 读 void 实况（自动适应新 void 形状） |
| 道路/河流锚点（`ComputeSeamCellForEdge`） | **统一锚点工具**：边中点沿外法向最外非 void 格（新 void 边界内侧第一格）再内偏 offsetCells（道路 `RoadAnchorInset=0` 贴边）；基于带几何，与带宽无关 |
| 建筑选址（`Patches_BuildingPlacement`） | 多边形几何判定（不变；带外圈格仍被六边形外判据拒绝建筑） |
| 渲染（`SeamlessTileRenderer`） | 整数 offset TRS 平移（不变；新 offset 公式消系统误差） |
| 归属裁决（`SeamlessTileRegistry`） | `IsCellInPolygon` 可见区判定（不变） |
