# 接缝带定义（权威）

> 状态定稿 2026-08。本文是接缝带几何的**唯一权威定义**，代码与文档统一用词以本文为准。
> 实现入口：`Source/Generation/SeamlessPolygonGeometry.cs`（`BuildSeamBand` / `SeamBandInfo`）。

## 0. 背景与动机

旧架构中"接缝带"没有显式定义：传送点带 = 距 void 边界切比雪夫 1..2 格（`ComputeVoidBand(N=SeamOverlap)`），
offset = 源图多边形镜像假设 `round(2·(midA−centerA) − SeamOverlap·unit)`。两图多边形各自用自己
tile 中心的切平面基独立投影，同一条世界共享边在两端局部坐标系中的内切距不等（顶点方向角间隔
差 1° ≈ 内切距差 ~1 格），镜像假设把 A 的内切距强加给 C → **系统性 ±1 格渲染错位**（2026-08 实测：
聚焦 C 时 C 的接缝带比 A 背景内偏一格；赤道正北侧同样复现，排除地块角度因素）。

本次重构把接缝带显式定义，并把偏差吸收职责从"offset 固定收缩 2 格"移交"3 圈接缝带"。

## 1. 术语体系

以**离散边为锚**的方向词：**接缝带内** = 核心侧（朝地图中心）；**接缝带外** = void 侧。

**禁止**用"六边形外/内"指格集合——离散边格横跨连续边，内外归属有歧义。"格中心在多边形内/外"
（`ContainsPointAt(格中心)`）仅作为无歧义的标量判定使用。

## 2. 定义

从核心区向外的圈层顺序：

```
核心区 → 带内圈 → 离散边圈 → 带外圈 → void（接缝带外）
        └──────── 接缝带 B ────────┘
```

| 术语 | 定义 |
|---|---|
| **连续边** | 多边形顶点（等边模型——目标边长 0.5S、半径 = 0.5S/相邻顶点方向平均弦长，正六边形下精确回落 0.5S、正五边形 ≈0.4253S；2026-08 修正勿回退为半径恒定——旧模型五边形边长 +17.6% 且五-六共享边两图投影不等长、offset 中点对齐后向边端发散 ~11 格超带吸收能力，`BuildPolygonVertices`）环连成的 n 条浮点线段 `(verts[j], verts[(j+1)%n])`。N=5/6 通用。 |
| **离散边 D（离散边圈）** | 格方块 `[x,x+1]×[z,z+1]` 与任一连续边线段**相交**（slab 法，含边界/角点接触）的格集合。横跨连续边，不参与内外分类。恰好经过四格公共角时 2×2 格都入 D。 |
| **接缝带 B** | `Cheb(D, 1)` = 离散边 + 切比雪夫内外各一圈，约 3 圈厚。对角接触被切比雪夫膨胀填满，**无洞**。 |
| **带内圈** | `B − D` 中格中心在多边形内的格。无传送点。 |
| **带外圈** | `B − D` 中格中心在多边形外的格。**实地形**（不再是 void），属传送圈。 |
| **传送圈** | `D ∪ 带外圈`（外侧 2 圈）。传送点按纯几何全量铺设，不做 `Standable` 过滤；实际主体能否通行由运行时路径成本与传送落点判据决定。 |
| **void（接缝带外）** | 格中心在多边形外且 `∉ B`。铺 `RimExodus_Void`。 |
| **核心区** | 格中心在多边形内且 `∉ B` 的格。 |
| **过渡带 T** | 接缝带内（核心侧）距 B ≥1 的**全部**格（膨胀到核心区穷尽）。SeamOverride 混合枚举范围（运行时 strip 无命中的格自然跳过）。 |
| **接缝带外条带** | 接缝带外（void 侧）**全部**格（膨胀到方形边穷尽）。void 区，其原生三层快照是新图混合的参考数据——**全深存储**（权重衰减轴需要：接近源六边形高 → 源方形边 0）。 |

### void 判定的防孤岛等价性

新判定"中心在外且 ∉B"取代旧"中心或 4 角任一在内→非 void"的角检测。凸多边形下，角在内的格
必属 `{中心在内} ∪ D`（格方块与多边形有面积交集 ⟺ 中心在内或某条边线段穿过格方块）⊆
`{中心在内} ∪ B`，故两者防孤岛等价；差集恰为带外圈（有意从 void 变实地形）。

### 传送圈为何只有外侧 2 圈

传送落点 = `spot − offset`，中点对齐的取整残差 ±1 格由对侧 3 圈带吸收：pawn 由内向外正常
移动必先踩**离散边圈** spot（更靠内），落点理想在对侧离散边圈，偏移最多落到对侧带内圈/带外圈
——均为实地形，不进 void。若带内圈也有传送点，站带内圈传送的落点偏移可能越过对侧带外圈落进
void。极端组合（站带外圈 + 对端近 1 格）落点 void 由 `Walkable` 检查严格拒绝（不做回退——
寻路已排除不可站立 spot，正常移动流不触发）。

## 3. offset：连续边中点对齐

```
offset(A→C) = round(midA_jA − midC_jC)
```

- 契约不变：`neighborLocal + offset = myLocal`；`midNew + offset = midSource` 即两端连续边中点平移后重合。
- jA/jC = 共享边在各自多边形中的边索引（`WorldTileGeometry.FindNeighborIndex`，"边 j ↔ 邻居 j"同构）。
- **双端几何参与**（旧镜像假设只用源端——系统性 ±1 格错位的根因，勿回退）。
- **无收缩**（旧 SeamOverlap 收缩已废弃；偏差吸收移交 3 圈带）。
- 天然对称：`round(−x) = −round(x)`，任一端计算结果一致；登记时算一次取负。
- 取整残差 ≤1 格/分量；渲染保持整数 TRS 平移（浮点平移会引入半格纹理错位，不做），
  残差由"带外圈实地形 + 重叠带地形完全一致 + 聚焦图覆盖"掩盖。
- 旧常量 `SeamOverlap` 改名 `RoadAnchorInset = 2`，仅剩道路锚点内偏语义。

## 4. SeamOverride：实时地图与基础快照参考

### 数据提供器（terrain / building / roof 三层）

不再捕获或持久化派生的条带快照。生成 C 时枚举其周围**实际存在于 `Find.Maps` 的表面邻图**；
单个采样格通常命中一张边邻图，六边形顶点处最多命中两张，并进入同一权重合成而非后写覆盖。
每个映射格 `a = c − offset` 按如下优先级取三层：

- `a ∈ B_A ∪ T_A(depth≤6)` 且当前地形非 null/void → **当前实况**（玩家开采、铺地、拆顶等修改会影响以后生成的邻图）；
- 当前格已被裁成 null/void，或 `a` 位于 void 外条带 → **389 裁切前的完整基础快照** `baseTerrainSnapshot` / `baseBuildingSnapshot` / `baseRoofSnapshot`；
- 两者都不可用 → **没有参考**，只跳过这一邻图的这一采样，不中断生成。

提供器用 `(has, value)` 区分“有参考且岩体/屋顶明确为空（value=null）”与“没有参考（has=false）”，
因此沙地的“无岩/无顶”会正常清除目标层，不会被误解为缺数据。

- 基础快照是**完整矩形图**，不是 void 裁去部分；它在 389 清理之前捕获，专门保存当前图已经无法直接读取的自然状态；
- building 层存岩石体 BuildingDef（自然岩石 + 矿石 isResourceRock，null=无；判据 `def.building.isNaturalRock`——`naturalTerrain` 只被引擎赋给非矿石天然岩（TerrainDefGenerator_Stone），2026-08 前的 naturalTerrain 判据把压埋钢铁等矿石全漏成"无岩体"）：照抄区 spawn 用对端 def（跨缝岩色/矿脉连续；原版岩石地形阈值 elevation≥0.61 与 Building 阈值 >0.7 不同的中间带状态正确继承）；`SyncRockBuildingTo` 三分支——无岩 spawn / 有岩 Destroy(Vanish) / **都有岩但 def 不同 → 替换（Vanish+spawn）**（矿 lump 边界两侧 def 必不同，不替换则跨缝"铁矿紧邻花岗岩"断裂残留；2026-08 修复）；
- roof 层存 RoofDef（null=无）：照抄区屋顶照抄对端（岩壁带原生岩顶 Thick/Thin，不裸顶）。

地块图的基础快照只驻内存；读档后若缺失，在下一张正式地图占用 `MapGenerator` 静态状态之前按需重建。
原生图现有的紧凑快照序列化继续保留，服务卸载恢复。封存图没有 Map，不参与接缝参考。

### 清理时序（全部归 389，勿在更早步骤预清）

order 200 的 `Patch_GenStepRocksFromGrid` 已删除（2026-08）。原生数据（含接缝带外条带的
岩体/屋顶）在 389 `BackupSnapshotAndApplyVoid` 先落三层快照，再由 `ApplyPolygonTerrain`
依次清 roof → rock（实体）→ terrain，最后 pathGrid 全量刷新

**基础三层快照的序列化（2026-08，卸载恢复支撑）**：原生 parent 图的三层快照以紧凑格式随
`SeamlessTileManager.baseSnapshotData`（`SeamlessBaseSnapshotData`）序列化——terrain 全格
ushort+去重 def 表、building/roof 稀疏（非空格 cellIndex+def 表索引）。开关
`serializeBaseSnapshots`（默认开）只门控**捕获**（保存时从内存数组捕入），已捕获数据照存
（清除 = 设置 UI 关开关二次确认流程的显式动作）；读档无条件还原内存数组——旧档无数据 = null
维持原降级，有数据则读档后 `DescribeCellReport` self 卷积参考可用（原"读档后回落当前"降级顺带消失）。
**地块图不序列化**（parent 为 RimExodus 类型、卸载恢复时必删，序列化纯浪费体积）；读档后需要

卸载前恢复原版兼容模式（`SeamlessUninstallRestore`，恢复仅回填 void 格——接缝带混合差异属观感、
原版可加载，不做全图归一）。（直写 topGrid 不触发重算，
不刷则后续步骤的 Standable/Walkable 读旧缓存——2026-08 动物站 void 的历史 bug 根因之一，
详见 doc/地图生成步骤.md 反转节）。历史教训：曾在 200 预清 void 格岩体，void 下原生
岩体在备份前丢失 → 新图照抄区岩壁整齐切断。

### 混合规则

SeamOverride 只做三件事：**按卷积权重覆盖、随机化边缘（dither）、道路修复（保护）**。规则轴 = **本端圈层**（对端只提供数据，不参与规则判定——错位天然免疫）：

- **c ∈ B_C（接缝带三圈）∪ T·1（过渡带 depth=1）→ 三层字面照抄对端参考格**：`a = c − offset`（镜像格 = 同一空间位置；两图接缝带在缝两侧空间重叠 3 圈）。有参考即抄地形、岩体和屋顶，无任何地形例外。参考优先用对端当前实况，当前格为 void 才回落基础快照。**T·1 并入照抄区**：本图 T depth=1 ↔ 对侧 OuterStrip depth=1 同一条空间带，后者从基础快照复刻自然岩体，兜住先生成侧 void rock 的 own-snapshot 假设。照抄与卷积只认渲染映射格 a = c − offset；切比雪夫圈对应不是渲染映射对应，勿再加参考内移。
- **c ∈ void_C → 不在枚举范围**：直接用自己的 void。
- **c ∈ T_C depth≥2（过渡带）→ 卷积权重覆盖（源地图轴权重；depth=1 已并入照抄区）**：w = `dSq/(dSq+dOut)`——dOut 直接由邻图 `SeamBandInfo` 计算，dSq = a 到源方形边切比雪夫距离。self（C 当前 topGrid 3×3）+ 各实时/基础参考（3×3，缺格跳过）加权取众数；岩体/屋顶跟随主导参考。乘性 dither、平局规则和特征保护不变。
- **顶点楔形区**（B_C 多邻居命中）：卷积合成（各 w=1，Σw ≥ 1 时 self 权重 0）——替代旧"串行后写者胜"。
- **唯一例外 = 道路保护**：路是 1-2 格窄结构，3×3 众数卷积必然抹掉（窗口内少数派），且路由 A* 权威生成——①本格 IsRoad/bridge 跳过；②`SeamlessRoadPaths` ±3 格切比雪夫缓冲兜底无 tag 路面（Gravel 等）。
- **水体无例外（用户定夺 2026-08，勿回退为裸 IsWater 或"不可走水体"判定）**：对端是水体本端就是水体——不能走 pawn 自然绕路（与地图中央的水体同构）；河/海走廊位置由 river patch 端点对齐权威保证，SeamOverride 的逐格混合负责接缝两侧地形一致，两者互补。历史的水体例外（本格 IsWater 跳过、卷积采样跳水）是旧 offset ±2 格系统误差下"防水蔓延"的补丁，中点对齐后不成立（其间还因 `HasTag("Water")` 前缀匹配误伤 WaterMarshy 的 Marsh 造成接缝断裂）。
- **单向**：只改 C。先生成者原生，后生成者服从（先生成时对端不存在是自然序）。

### 旧候选枚举废弃

旧方案从 A 全图 snapshot 枚举候选（`cCell = aCell + offset` 落 C 六边形内）——A 方形角落格
绕六边形顶点投影进 C 侧向楔形区的污染（`A(249,249)→C(59,146)` 实测数据点）由此结构性消失：
只枚举 C 的带格，每格反向找邻居参考。

## 5. 地图生命周期（滚动软休眠，2026-08 已实现；权威文档 = `doc/地图滚动休眠.md`）

| 状态 | 现状对应 | 接缝参考数据 |
|---|---|---|
| 已加载（活跃） | 图在 `Find.Maps`（全量模拟、随存档序列化、读档恢复不重生成） | 带内取当前实况，void 侧取完整基础快照 |
| 软休眠 | Map 对象仍在 `Find.Maps`，只停 tick / 摘邻接显示 / 关访问入口 | 仍是实际存在的 Map，可作为接缝参考 |
| 封存 | 仅保留 `ZoneMapRecord` 与 WorldObject，Map 已拆除 | **不参与参考**；恢复时重生成自然外围、与届时已加载邻图混合，再重放居住区 |
| 完全卸载 | `RemoveTileMap`（销毁 Map **和** WorldObject = "从未出现过"）：governor 距离 ≥3 跳自动执行（家园/锚点图永不删除），Dev Remove All Tile Maps / Force Delete 同路径 | 无 |

**读档缺口修复**：原版同步 `MapGenerator.GenerateMap` 的 Prefix 与分帧 `IncrementalMapGenerator.Start`
在占用生成静态状态之前调用同一准备入口，枚举目标 tile 周围全部实际加载邻图，并逐张补齐缺失基础快照。
MapPreview、口袋图和空间层跳过。单图重建失败只使其缺失的 void 侧采样跳过，并记 Warning。
