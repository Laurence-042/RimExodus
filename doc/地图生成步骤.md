# RimWorld 完整地图生成步骤（含 RimExodus 注入点）

本文档记录 RimWorld 地图生成的完整 genStep 执行顺序，并标注 RimExodus 在哪里插入了什么。
目的是让后续开发快速恢复"原版做了什么、我们在哪一步介入"的上下文。

> **排序规则**（`MapGenerator.cs:MapGeneratorPostInit`）：`orderby def.order, def.index`。
> genStep 按 `GenStepDef.order` 升序执行，order 相同时按 `Def.index`（加载顺序）决胜。
> **MapGeneratorDef 里 XML `<li>` 列表顺序不影响执行顺序**——只决定包含哪些 GenStepDef。

## 注入目标

RimExodus 通过 `1.6/Patches/MapGeneration.xml` 的 `PatchOperationAdd`，把三个自定义 GenStepDef
追加到三个 `MapGeneratorDef` 的 `genSteps` 列表：

- **`Base_Player`** — 玩家家园（锚点 A）+ 邻接地块地图（B/C）复用此链。
- **`Base_Faction`** — 派系基地。
- **`Encounter`** — 遭遇/任务地点。

三者都继承自 `MapCommonBase`（抽象父类），共用大部分 genStep。

## 关键时序约束

1. **snapshot 备份必须在 1400（而非更早）**：order 400+ 有写 topGrid 的步骤——Settlement(400)/各 site 结构的 BaseGen `SymbolResolver_FloorFill`→`SetTerrain` 铺地板，MutatorCriticalStructures(500) 的 Harbor/ArcheanTrees 铺地形。这些地板可能延伸到 A 被 void 裁掉的边缘条带，提前备份会导致 SeamOverride 卷积用旧地形而非最终地形（snapshot 漂移）。Plants(900)/Animals(1200)/Snow(1150) **不写 topGrid**（只 spawn Thing / 写 tempGrid），对 snapshot 无影响。
2. **void 铺设在 1400 的原因**：void 地形 Impassable/fertility=0，Plants/Animals/GenSpawn 都会正确跳过 void 格（已查证 `GenSpawn.CanSpawnAt` 查 Walkable、植物查 fertility）——所以理论上 void 提前铺不会导致实体 spawn 在 void 上。但它必须和 snapshot 备份耦合在同一个 genStep（备份在铺 void 前），故随 snapshot 一起在 1400。
3. **SeamOverride 必须在 void(1400) 之后、Fog(1500) 之前**：读两端 snapshot + 写覆写后的地形，让 Fog 基于最终地形揭雾。另：SeamOverride 若在建筑生成(400+)之前跑，其 SyncRockBuilding 的岩石 spawn 会干扰 Settlement 选址，且 BaseGen FloorFill 会覆盖混合带卷积结果。
4. **道路 patch 在 390 靠多边形几何算锚点**：因为接缝带/传送点要到 1400 后才存在，390 时不能查 `SeamlessEdgeCells`。
5. **MutatorFinal(1600) 对地形的影响**：多数 mutator 不写 topGrid，但 AncientUplink/InsectMegahive 的 `GeneratePostFog` 会 `SetTerrain`——这些任务地块上 1410 的覆写可能被 1600 覆盖（已知小瑕疵，罕见场景）。

## 已否决：把 SeamlessTile/SeamOverride 提前到 391-399

考虑过移到 Roads(390) 之后（"400+ 看起来只是建筑"），分析后否决：

- **否决原因①（snapshot 漂移）**：order 400+ 并非只生成建筑——Settlement/site 的 BaseGen 地板、Harbor(500) 的桥都会写 topGrid。391 备份 snapshot 会漏掉这些，卷积用旧地形。
- **否决原因②（卷积被覆盖）**：SeamOverride 若在 392-399 跑，之后 Settlement(400) 的 FloorFill 会在混合带格上再铺地板，直接盖掉卷积结果；SyncRockBuilding spawn 的岩石还会干扰 Settlement 选址（Standable 检查）。
- **成立的部分**：void 铺设后 spawn 跳过是安全的（Impassable/fertility=0 网关齐全），但这不构成移动的理由。
- **注意**：MutatorFinal(1600) 的 AncientUplink/InsectMegahive 写地形发生在 1410 之后，无论放哪都存在此瑕疵。
