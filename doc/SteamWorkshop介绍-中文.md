[h1]RimExodus — 无缝世界[/h1]

告别"撤离地图 → 世界地图 → 重新加载"的割裂旅行。RimExodus 让相邻世界地块的局部地图在视觉与操作上连续连接：殖民者从基地门口直接走进荒野，穿过看不见的地块边界走向下一片荒野——不需要远行队，不需要加载画面。

[img]https://raw.githubusercontent.com/Laurence-042/RimExodus/main/doc/img/demo.gif[/img]

[b]⚠ 本 mod 仍在开发中：对地图机制改动较深，可能在奇怪的地方出 bug。存档格式已基本固定，出问题欢迎反馈。卸载前请先运行设置中的"恢复原版兼容模式"按钮，恢复后存档即可卸载；首次读档有一批无害红字，再存一次即消失。但受地图生成机制所限仍有些限制，详见讨论区"关于卸载"帖。[/b]

[h1]它做了什么[/h1]

每张地块地图按世界地块形状裁切成六边形（五边形同样支持），相邻地块通过"接缝带"对齐：地形、岩石、屋顶跨缝混合，河流与道路跨缝对接。走到接缝处，邻居地块的实时地形已渲染在边界之外，殖民者可直接跨过边界——简单来说，Rimworld大世界模式，启动！

[img]https://raw.githubusercontent.com/Laurence-042/RimExodus/main/doc/img/map-grid.png[/img]
地图网格化裁切与接缝对齐

[list]
[*][b]直接跨图行走[/b]：命令殖民者接近接缝来生成相邻地图，命令殖民者跨过两图接缝几乎无感切换到相邻地图，命令殖民者站到接缝上使其成为原版远行队。

[*][b]跨图战斗[/b]：跨缝视线与索敌、射击与弹道交接——子弹飞过接缝，在正确的地图上命中正确的目标；你可以跨图追击逃窜的敌人，敌人也会跨图追击你。可在设置中整体关闭回到原版战斗语义。

[img]https://raw.githubusercontent.com/Laurence-042/RimExodus/main/doc/img/shoot.png[/img]
跨缝射击

[*][b]分帧增量生成[/b]：邻居地块地图在殖民者被命令靠近边界时开始生成，大部分时候不暂停游戏、也无加载画面（生成过程中无法存档，也就几秒的事）。

[*][b]地图滚动休眠[/b]：远离玩家的地图自动休眠（停止 tick，内容完好保留、可随时唤醒折返），更远的地图删除、再访时重新生成。注意：重新生成是全新的，遗留物品、建筑与地形修改都会丢失。家园地图永不自动休眠、删除。休眠/删除距离均可在设置中调整。

[*][b]原生内容接入[/b]：世界地图 POI——其他派系据点、远古机械师建筑群、埋伏、机会地点——走近时经原版生成管线生成为无缝地块，与其他 mod 的自定义结构天然兼容；"设立营地"也是无缝地块。

[*][b]据点贸易商[/b]：友好据点从驻军中指定一位"贸易商"（头顶问号标记），右键即可对话交易——买用据点库存、卖随身物品、白银随身支付，完整原版远行队交易语义，无需真的组队。对话面板同时收录该据点全部交互选项，包括其他 mod 添加的（比如金鸢尾兰的外交选项）。

[img]https://raw.githubusercontent.com/Laurence-042/RimExodus/main/doc/img/trade.png[/img]
与据点贸易商交易

[*][b]世界地图三态图标[/b]：地块图标实时显示活跃/休眠状态，选中可手动休眠或删除。
[/list]

[h1]Mod 兼容性[/h1]

理论上只要不涉及修改基础地图（也就是星球视图每个地块的地图），基础能力都适配。

[b]已适配：[/b]
[list]
[*][b]Geological Landforms[/b] — 整体适配，可以正常生成地貌，但河流的无缝拼接尚未适配完成。

[*][b]MapPreview[/b] — 预览可见符合实际的地形生成。

[*][b]Vehicle Framework[/b] — 载具可跨缝：驶近传送点即跨越、可跨图下令，多格大型载具做了整车落点校验（对端放不下时如实拒绝）。滚动休眠中载具视同 pawn。

[*][b]Vehicle Map Framework[/b] — 载具地图上带着殖民者时，载具可以正常跨图

[*][b]Perspective Shift[/b] — 第一人称 WASD 移动可正常跨图，跨图射击也没问题。
[/list]

[b]预期不兼容：[/b]
[list]
[*][b]边缘战争空岛[/b] — 空岛改造流程会破坏本mod的地图设置，空岛地图无法无缝；空岛移动逻辑也未深入调研，可能另有问题。玩法调性冲突，不计划支持。
[*][b]CE[/b] —  它当然兼容Character Editor。至于Combat Extended……跨缝射击暂不支持，但单图内战斗兼容。我想先保证mod和原版功能兼容良好，再做跨缝战斗和相关mod适配。
[*][b]As above, So below 2[/b] — 地图假设完全冲突：它必须修改地图尺寸并自定义切分，RimExodus 无法在这种前提下维持地块边界平滑过渡。但老牌多层mod MultiFloors 是适配的。

[*][b]深度修改地图生成管线/地图边界/世界地块的其他 mod [/b] — 未系统测试，若遇冲突，可关闭设置中的"分帧生成开关"让普通地块图改走原版同步生成管线（其他 mod 的 patch 由此生效，代价是生成时短暂冻结）。
[/list]

[h1]已知限制[/h1]

[list]
[*]天气被强制修改后，若修改源未处理（如游戏条件未结束）其所在地图就被删除，天气将无法恢复——恢复途径随修改源一起被删了。

[*]挖矿/砍伐等"designation 前置型"命令不出现在跨图右键菜单（走近过缝后一切正常）。

[*]不会做跨图搬运等跨图工作支持，这个mod设计背景是为了让Odyssey更Odyssey，而不是建造超大基地。

[*]Odyssey 空间层地图与各类口袋图（Pocket Map，比如地下仓库、巨坑、 VMF 的载具内部图之类的）不参与表面无缝语义，保持原版行为。

[*]据点交易仅支持随身物品（随行囚犯/奴隶出售暂不支持）；贸易商为生成时一次性指定，不补选。

[*]分帧生成邻接地图的过程中（进度显示在屏幕左上角）无法存档。

[*]邻居地图渲染为近似实现（无阴影/水波等细节），跨天气域的邻居天色跟随当前图。

[*]星球上的12个五边形地块周围一圈的地图连接视觉上会有点问题，但不影响跨图移动。

[*]原生成在地图边缘的袭击会生成在接缝附近，不论对侧是否已加载地图（之后可能优化为从已加载地图外围生成，未定，需先调研可能冲突的mod实现）
[/list]

[h1]性能[/h1]

无跨图行为和地图生成时几乎零开销，但地图过多本身就是 Rimworld 的性能问题——不过本mod改善了它。除休眠不再 tick、远图删除外，还可设置**无人的非家园地图的 tick 倍率**，以及**接缝周围多少格无视倍率全速运行**（保住跨图战斗）。

把这两个参数都设为 0、14 张活跃图全是草原雨林的极端压力测试下，5 年前的笔记本（初代 OMEN 16）实测 360 TPS。
